# Admin Dashboard

A responsive dashboard built as part of The Odin Project curriculum. The project focuses on creating a complex dashboard layout using modern CSS techniques, with an emphasis on CSS Grid, Flexbox, and responsive design.

Project from [The Odin Project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-admin-dashboard) — HTML & CSS course.

## Live Demo
[View Demo](https://ttnluong.github.io/odin-admin-dashboard/)

## Features
- Responsive dashboard layout
- Sidebar navigation menu
- Project overview cards
- Modern UI built with CSS Grid and Flexbox

## Built With
- HTML5
- CSS3
- CSS Grid
- Flexbox
